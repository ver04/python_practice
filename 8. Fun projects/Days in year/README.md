# Days in Year

A web frontend for tracking the progress through the year by showing the current day as "Chapter" and visualizing it as "Year XXXX | Chapter XXX/365".

The frontend displays:
- Large bold text showing current year
- A separator (|)
- Green glowing chapter count (current day/total days in year)
- Automatic real-time updates

---

Celebrate your progress through the year, one chapter at a time!
